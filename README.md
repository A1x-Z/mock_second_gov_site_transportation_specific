# Riverton Department of Transportation (mock)

A mock transportation-agency website for local testing. It is a themed copy of the general 311 mock site, with no report-submission API. Another service can later open this site in a browser (for example with Playwright), fill the public form, and read the confirmation page.

## Run

```bash
npm install
npm run dev
```

The app is served at `http://localhost:3001`.
